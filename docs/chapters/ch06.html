AI Tutorial: An LLM News-Sentiment Signal

This tutorial shows how generative AI fits into the trading research workflow described in Chapter 6 and builds one concrete component: a daily news-sentiment signal produced by a large language model. It is the first of two trading tutorials. The second, on the Chapter 7 page, builds and backtests a complete ML trading system on SPY, to which this signal can be added as a feature. The code is in this page’s companion notebook.

Generative AI as a Research and Development Copilot

The traditional quantitative workflow has a human researcher design features, select models, write code, and interpret results. Generative AI is changing this workflow, not by replacing the quant, but by compressing the research cycle from weeks to hours.

The new quant workflow. Large language models such as Claude, GPT, and Gemini have moved from experimental curiosities to core productivity tools at major quantitative firms. A 2024 industry analysis estimated that generative AI delivers approximately 20% productivity gains at funds that have integrated it into their research pipelines (International Monetary Fund 2024). The use cases fall into three tiers:

  1. Strategy ideation and hypothesis generation. Quants describe a trading idea in natural language (for example, “a mean-reversion strategy on S&P 500 constituents that enters when RSI crosses below 30 and exits at the 20-day moving average”) and the LLM translates it into a mathematical specification or working code. The Alpha-GPT system (Wang et al. 2023) pioneered this approach: in the WorldQuant International Quant Championship 2024, it ranked in the top 10 out of 41,000 teams, achieving in a single day what human participants typically needed a month to accomplish.

  2. Code generation and backtesting acceleration. AI coding assistants (GitHub Copilot, Cursor, and Claude Code) generate Python pipelines for data ingestion, feature engineering, and walk-forward backtesting directly from natural-language descriptions. Their large context windows make them suited to analyzing and refactoring large existing codebases, a common task in established quant shops where legacy systems span tens of thousands of lines. In practical terms, a researcher can describe a pipeline like the one built in the Chapter 7 tutorial and receive a working first draft in minutes rather than hours.

  3. Document analysis and signal extraction. LLMs can scan and summarize dozens of earnings transcripts overnight, extract risk factors from 10-K filings, and synthesize alternative data streams into structured signals. MarketSenseAI 2.0 (Fatouros et al. 2025) combined retrieval-augmented generation (RAG) with LLM agents to process SEC filings and earnings calls for S&P 100 stocks, producing cumulative returns of 125.9% over 2023–2024 versus 73.5% for the index.

The following example demonstrates how an LLM can be used as a financial news sentiment classifier within a trading pipeline. Rather than fine-tuning a model on labeled data (the FinBERT approach), it calls the Anthropic API to classify headlines in a zero-shot setting, with no training data required. The function classify_sentiment sends a list of headlines to a Claude model and asks for a JSON array in which each object carries the original headline, a sentiment label (BULLISH, BEARISH, or NEUTRAL), and a confidence score in \([0,1]\). The parser removes optional Markdown fences and validates completion status, record count, original-headline order, sentiment labels and confidence bounds.

The five headlines are synthetic illustrative inputs, short, hand-written strings chosen to exercise distinct cases (a dovish Fed signal, an earnings miss, a neutral data print, a cross-asset oil shock, and a confidence reading) rather than a live news feed. The classifications shown in the output block are a representative example of the kind of response such a prompt elicits, not a captured transcript of a specific API call; because the model is queried live and at nonzero temperature by default, exact labels and confidence values will vary from run to run. Treating the output as illustrative rather than reproducible is important: this block depends on an external, evolving model and a network call, while the market-data workflow in the Chapter 7 tutorial also depends on vendor history and library versions.

import anthropic
import json
import os
import math

client = anthropic.Anthropic()  # uses ANTHROPIC_API_KEY env variable

def classify_sentiment(headlines: list[str]) -> list[dict]:
    """Classify financial headlines using Claude as a zero-shot sentiment model."""
    prompt = f"""Classify each financial headline as BULLISH, BEARISH, or NEUTRAL.
Return ONLY a JSON array with objects containing "headline", "sentiment",
and "confidence" (0-1). Headlines:
{chr(10).join(f'{i+1}. {h}' for i, h in enumerate(headlines))}"""

    response = client.messages.create(
        model=os.getenv("ANTHROPIC_MODEL", "claude-sonnet-5-5"),
        max_tokens=1024,
        messages=[{"role": "user", "content": prompt}]
    )
    if response.stop_reason != 'end_turn':
        raise ValueError('Sentiment response was incomplete; do not trade on it.')
    raw = ''.join(block.text for block in response.content if block.type == 'text').strip()
    if raw.startswith('```') and raw.endswith('```'):
        raw = '\n'.join(raw.splitlines()[1:-1])
    records = json.loads(raw)
    if not isinstance(records, list) or len(records) != len(headlines):
        raise ValueError('Expected one classification per input headline.')
    for headline, record in zip(headlines, records):
        if not isinstance(record, dict) or record.get('headline') != headline:
            raise ValueError('Response headlines must match inputs in order.')
        confidence = record.get('confidence')
        if (record.get('sentiment') not in {'BULLISH', 'BEARISH', 'NEUTRAL'}
                or isinstance(confidence, bool)
                or not isinstance(confidence, (int, float))
                or not math.isfinite(confidence) or not 0 <= confidence <= 1):
            raise ValueError('Invalid sentiment label or confidence.')
    return records

# Example: classify today's headlines for SPY-relevant news
headlines = [
    "Fed signals potential rate cut amid cooling inflation data",
    "Major tech earnings disappoint, Nasdaq futures drop 2%",
    "US manufacturing PMI holds steady at 51.2 in October",
    "Oil prices surge after OPEC announces surprise production cut",
    "Consumer confidence index rises to highest level since 2021"
]

sentiment_results = classify_sentiment(headlines)
for r in sentiment_results:
    print(f"  [{r['sentiment']:>7s}] (conf: {r['confidence']:.2f})  {r['headline']}")
  [BULLISH] (conf: 0.85)  Fed signals potential rate cut amid cooling inflation
  [BEARISH] (conf: 0.90)  Major tech earnings disappoint, Nasdaq futures drop 2%
  [NEUTRAL] (conf: 0.80)  US manufacturing PMI holds steady at 51.2 in October
  [BEARISH] (conf: 0.65)  Oil prices surge after OPEC announces surprise production cut
  [BULLISH] (conf: 0.80)  Consumer confidence index rises to highest level since 2021

These hypothetical classifications illustrate an interface, not verified judgments. An oil-price increase can have different implications for different assets, and a model's self-reported confidence is not a calibrated probability. Any resulting trading feature needs its own held-out evaluation.

To integrate classifications into a daily signal, each record needs a timezone-aware publication timestamp and available_at timestamp identifying when ingestion and classification completed. The helper filters to the requested New York session date and requires availability by an explicit after-close cutoff as_of. It then averages signed model-confidence scores. Same-calendar-day matching alone could include headlines released after the decision. Retrospective classification with a model released after the backtest window remains a separate research limitation.

The result is a continuous score on a [-1, +1] scale: \(+1\) is unanimous high-confidence bullishness, \(-1\) unanimous high-confidence bearishness, and \(0\) either genuine balance or, on days with no coverage, an imputed neutral. That imputation choice is the design decision worth flagging, and the post-code note returns to it.

import numpy as np
import pandas as pd


def daily_sentiment_signal(headlines_with_timestamps, date, as_of):
    """Use only same-day headlines actually available by an aware cutoff."""
    cutoff = pd.Timestamp(as_of)
    session_date = pd.Timestamp(date).date()
    sentiment_map = {'BULLISH': 1.0, 'NEUTRAL': 0.0, 'BEARISH': -1.0}
    scores = []
    for h in headlines_with_timestamps:
        published, available = pd.Timestamp(h['timestamp']), pd.Timestamp(h['available_at'])
        if published.tz_convert('America/New_York').date() != session_date or available > cutoff:
            continue
        confidence = float(h['confidence'])
        scores.append(sentiment_map[h['sentiment']] * confidence)
    return float(np.mean(scores)) if scores else 0.0  # imputed neutral

# Availability includes ingestion and classification delay, not just publication.
sample_news = [
    {'timestamp': '2024-10-01T15:00:00-04:00',
     'available_at': '2024-10-01T15:01:00-04:00',
     'sentiment': 'BULLISH', 'confidence': 0.8},
    {'timestamp': '2024-10-01T17:00:00-04:00',
     'available_at': '2024-10-01T17:01:00-04:00',
     'sentiment': 'BEARISH', 'confidence': 0.9},
]
print(daily_sentiment_signal(sample_news, '2024-10-01', '2024-10-01T16:05:00-04:00'))

This produces a daily sentiment feature in the range \([-1, +1]\) that can be appended to the 18 technical features built in Phase 1 of the Chapter 7 tutorial. The key design decision is how to handle days with no news coverage. Here we impute neutral (0.0), but carrying forward the last observation or flagging it as missing are viable alternatives that should be tested for robustness.

Agentic AI in production. A notable development in 2025 is the deployment of multi-agent AI systems at major hedge funds, architectures where specialized LLM agents collaborate on different stages of the research process, replicating the division of labor on a quantitative trading desk. Man Group’s AlphaGPT system deploys distinct agents for search, interpretation, reasoning challenge, and final sign-off, and had produced several dozen investment signals approved for live trading as of mid-2025 (Group 2025). Bridgewater Associates launched a $2 billion fund in 2024 that uses ML as the primary basis for decision-making, combining models from OpenAI, Anthropic, and Perplexity in a platform where domain experts construct multi-step “blueprints” that chain together LLM queries for complex investment analysis (https://www.bridgewater.com/) (Bridgewater Associates 2024).

Open-source tools. The barrier to entry has dropped considerably. FinGPT (Yang, Liu, and Wang 2023) fine-tunes open-source LLMs (LLaMA-based) for financial tasks at less than $300 per training run, achieving sentiment analysis F1 scores up to 87.6%. FinRL (Liu et al. 2021) provides a complete reinforcement learning framework for portfolio optimization and execution. Microsoft’s RD-Agent automates the quant research pipeline by decomposing factor mining and model optimization into five LLM-powered stages: specification, synthesis, implementation, validation, and analysis.

Despite these results, rigorous evaluations point in a more sobering direction. Emerging benchmark evaluations of frontier LLM agents reportedly placed multiple frontier models on live equity trading over short evaluation windows and found that, by these accounts, most LLM agents struggle to consistently outperform simple buy-and-hold. If these findings hold up under independent replication, they would mirror the results of the Chapter 7 tutorial: even sophisticated models find it difficult to beat a passive benchmark on daily equity data. The IMF’s October 2024 Global Financial Stability Report noted that AI content in algorithmic trading patent applications rose from 19% in 2017 to over 50% since 2020 (International Monetary Fund 2024), but cautioned that AI-driven ETFs showed increased herding behavior during the March 2020 turmoil. The implication is that generative AI accelerates research but does not shortcut alpha generation. The hard problems of financial prediction (low signal-to-noise ratios, non-stationarity, and adversarial market dynamics) persist.

Summary

You saw where generative AI fits in the quantitative research workflow and built a daily news-sentiment signal with a language model, using availability timestamps so the signal uses only headlines known at the decision time. The Chapter 7 tutorial builds the trading system this signal can feed.
