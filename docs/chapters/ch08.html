AI Tutorial, Part 1: Data and Factor-Based Stock Selection

This tutorial implements the first half of an equity investment pipeline: data acquisition and factor-based stock selection. Part 2, which accompanies Chapter 9, continues from the selected stocks to constrained portfolio optimization, backtesting, and performance evaluation. We use real market data from S&P 500 constituents, demonstrating practical techniques that can be extended to production systems.

The implementation emphasizes reproducibility and transparency. All code uses open-source libraries available via pip, and data is sourced from Yahoo Finance (freely accessible). While production systems would incorporate additional data sources and more sophisticated models, this tutorial establishes the foundational workflow that underlies institutional equity strategies.

Environment Setup and Data Acquisition

This first block downloads five years of real daily prices for an equity universe and defines the workflow’s data backbone. Unlike most tutorials in this book, the data here is not synthetic: yf.download pulls actual adjusted-close prices from Yahoo Finance for the 52 tickers in UNIVERSE (eight names each from technology, healthcare, financials, consumer, and industrials, plus energy/materials and utilities/REITs) and for the BENCHMARK ticker SPY. The window runs from 2019-01-01 to 2024-01-01, so the prices span the pre-pandemic market, the COVID crash and recovery, the 2021 mega-cap rally, and the 2022 drawdown. Adjusted close is used (rather than raw close) so that splits and dividends do not show up as spurious returns.

The download_stock_data function requests adjusted closes explicitly, verifies the benchmark and preserves missing observations. Stock eligibility is determined separately at each historical decision using only its trailing window; filtering by full-period missingness would use future information. The requested universe contains 52 stocks plus SPY, although data availability depends on the vendor. This fixed universe still carries survivorship bias. The following listings print results from the downloaded data; historical numerical tables are omitted because they do not represent the corrected workflow or the current fundamental snapshot.

This block is real-data acquisition with no injected structure; the factors, returns, and portfolios built later all derive from these prices. In a production research stack, the Yahoo feed would be replaced by a point-in-time vendor (CRSP, Compustat, Bloomberg) that records which stocks were in the index on each historical date, which is exactly the survivorship correction the next paragraph describes. The fundamental-data and factor steps that follow connect back to the factor models introduced in the Conceptual Foundations section, and Part 2 feeds them into the mean-variance framework of Chapter 9.

import os
from pathlib import Path

import numpy as np
import pandas as pd
import yfinance as yf
from scipy.optimize import minimize

from sklearn.linear_model import LinearRegression
import matplotlib.pyplot as plt
from datetime import datetime, timedelta
import warnings

# Define a fixed illustrative investment universe: 52 stocks across sectors.
# Historical membership is not reconstructed, so survivorship bias remains.
UNIVERSE = [
    # Technology
    'AAPL', 'MSFT', 'GOOGL', 'META', 'NVDA', 'AVGO', 'CSCO', 'ORCL',
    # Healthcare
    'JNJ', 'UNH', 'PFE', 'ABBV', 'MRK', 'LLY', 'TMO', 'ABT',
    # Financials
    'JPM', 'BAC', 'WFC', 'GS', 'MS', 'BLK', 'AXP', 'C',
    # Consumer
    'AMZN', 'HD', 'MCD', 'NKE', 'SBUX', 'TGT', 'COST', 'WMT',
    # Industrials
    'CAT', 'HON', 'UPS', 'RTX', 'LMT', 'GE', 'MMM', 'BA',
    # Energy & Materials

    # Utilities & REITs
    'NEE', 'DUK', 'SO', 'PLD'
]

# Benchmark: S&P 500 ETF
BENCHMARK = 'SPY'

def download_stock_data(tickers, start_date, end_date):
    """Download adjusted close prices for a list of tickers."""
    all_tickers = list(dict.fromkeys(list(tickers) + [BENCHMARK]))
    snapshot = Path('data/prices_2019_2024.csv')
    if snapshot.exists() and os.environ.get('REFRESH_MARKET_DATA') != '1':
        data = pd.read_csv(snapshot, index_col=0, parse_dates=True)
        data = data.reindex(columns=all_tickers).sort_index()
    else:
        raw = yf.download(all_tickers, start=start_date, end=end_date,
                          auto_adjust=False, progress=False)
        if raw is None or raw.empty or 'Adj Close' not in raw.columns.get_level_values(0):
            raise ValueError("No adjusted prices returned; check the data service.")
        data = raw['Adj Close'].reindex(columns=all_tickers).sort_index()
    if data[BENCHMARK].dropna().empty:
        raise ValueError("Benchmark adjusted prices are unavailable.")
    if (data <= 0).any().any() or np.isinf(data.to_numpy()).any():
        raise ValueError("Adjusted prices must be positive and finite where observed.")
    # Do not select stocks using missingness over the full future test period.
    # Each rebalance will use only its trailing history to establish eligibility.
    return data

# Download 5 years of data for backtesting
END_DATE = '2024-01-01'
START_DATE = '2019-01-01'

print("Downloading stock data...")
prices = download_stock_data(UNIVERSE, START_DATE, END_DATE)
print(f"Downloaded data for {len(prices.columns)-1} stocks plus benchmark")
print(f"Date range: {prices.index[0].date()} to {prices.index[-1].date()}")
print(f"Total trading days: {len(prices)}")

Survivorship Bias Warning: This tutorial uses current S&P 500 constituents, which introduces survivorship bias because we only include companies that survived and thrived through 2024. Companies that failed, were acquired, or dropped from the index are excluded. This systematically overstates historical returns because we exclude poor performers ex post. In production research, one should use point-in-time index membership data (available from providers like CRSP or Compustat) that reflects which stocks were actually in the index at each historical date. The magnitude of survivorship bias can be 1–2% annually for strategies tested over multi-year periods.

Computing Returns and Fundamental Data

This block turns the price panel into the two raw materials the rest of the pipeline needs: a return series for risk and momentum estimation, and a snapshot of fundamentals for the value and quality factors. compute_returns produces both daily_returns and monthly_returns, the latter sampled on the last trading day of each month. Everything downstream in this chapter, covariance estimation included, runs on the monthly series and annualizes by twelve; daily_returns is returned for your own extensions and is not used again below. get_fundamental_data then loads the bundled fundamentals snapshot, dated 21 September 2026, for each ticker’s pe_ratio (trailing price-to-earnings), pb_ratio (price-to-book), roe (return on equity), debt_to_equity, market_cap, dividend_yield, beta, and profit_margin. These map directly onto the valuation and quality metrics defined in the Fundamental Analysis section.

The fundamentals are a single dated snapshot, taken on 21 September 2026 and bundled with the notebook so the ranking below reproduces. Because that date is later than the 2019–2023 price window, the snapshot is not point-in-time data for this period: it demonstrates factor-ranking and optimization mechanics and must not be applied to past decisions. The historical backtest below defaults to price-only momentum and low-volatility factors. A four-factor backtest requires a callable that returns as-reported fundamentals available at each signal date. A current DataFrame is rejected. Extremely high ROE or P/B can reflect small or negative book equity; nonpositive valuation denominators and negative debt/equity are excluded from the corresponding score.

In production, fundamentals would come from a provider that timestamps each figure to its filing date (Bloomberg, FactSet, Refinitiv) and would be refreshed quarterly so that the backtest only ever sees data that existed at the time. The factor construction in the next subsection consumes both objects produced here, monthly_returns for momentum and volatility, fundamentals for value and quality.

def compute_returns(prices):
    """Compute daily and monthly returns from prices."""
    daily_returns = prices.pct_change(fill_method=None).iloc[1:]

    # Monthly returns (last trading day of each month)
    # Keep the actual last row: resample().last() would skip missing closes.
    monthly_prices = prices.resample(pd.offsets.MonthEnd()).agg(lambda x: x.iloc[-1] if len(x) else np.nan)
    monthly_returns = monthly_prices.pct_change(fill_method=None).iloc[1:]

    return daily_returns, monthly_returns

daily_returns, monthly_returns = compute_returns(prices)

def get_fundamental_data(tickers):
    """Retrieve fundamental data for factor construction."""
    # A pinned snapshot with a stated as-of date. yf.Ticker().info returns
    # whatever the market looks like today, with no historical as-of, so a
    # live fetch silently changes every ranking and weight below.
    snapshot = Path('data/fundamentals_snapshot.csv')
    if snapshot.exists() and os.environ.get('REFRESH_MARKET_DATA') != '1':
        return pd.read_csv(snapshot, index_col='ticker')

    fundamentals = []

    for ticker in tickers:
        if ticker == BENCHMARK:
            continue
        try:
            stock = yf.Ticker(ticker)
            info = stock.info

            fundamentals.append({
                'ticker': ticker,
                'pe_ratio': info.get('trailingPE', np.nan),
                'pb_ratio': info.get('priceToBook', np.nan),
                'roe': info.get('returnOnEquity', np.nan),
                'debt_to_equity': info.get('debtToEquity', np.nan),
                'market_cap': info.get('marketCap', np.nan),
                'dividend_yield': info.get('dividendYield', np.nan),
                'beta': info.get('beta', np.nan),
                'profit_margin': info.get('profitMargins', np.nan)
            })
        except Exception as e:
            warnings.warn(f'Fundamentals unavailable for {ticker}: {e}')

    if not fundamentals:
        raise ValueError('No fundamentals returned; retry the live snapshot separately.')
    df = pd.DataFrame(fundamentals).set_index('ticker')
    return df

print("Fetching fundamental data...")
fundamentals = get_fundamental_data(UNIVERSE)
print(f"Retrieved fundamentals for {len(fundamentals)} stocks")
print("\nSample fundamental data:")
print(fundamentals[['pe_ratio', 'pb_ratio', 'roe', 'market_cap']].head(10))

Factor-Based Stock Ranking and Screening

This block scores every stock on four factors, value, quality, momentum, and low volatility, and combines them into a single composite rank, operationalizing the factor models from the Factor-Based Investing section. Each raw factor is turned into a cross-sectional percentile via rank_normalize (so a score of 1.0 means best-in-universe and 0.5 is median), which makes the four factors comparable before they are blended. Value uses inverted P/E and P/B (cheaper is better), quality averages ROE, low leverage, and profit margin, momentum is the 12-month return skipping the most recent month (compute_momentum_factor with lookback=12, skip=1, a twelve-return window with the latest month skipped, requiring thirteen months of data), and low volatility is the negative of trailing annualized standard deviation so that calmer stocks score higher.

Two modeling choices shape the rankings. First, P/E, P/B and debt/equity are clipped before percentile ranking. Percentile ranks already limit sensitivity to outlier magnitude; clipping creates ties above each cap and sacrifices distinctions at the extremes, rather than preventing an extreme value from dominating all ranks. Second, the snapshot demonstration uses fixed weights (momentum 0.30, value 0.25, quality 0.25, low volatility 0.20). Missing scores are imputed at neutral 0.5; this makes an explicit missing-data assumption and need not be harmless. The historical price-only variant instead assigns 60% to momentum and 40% to low volatility.

The printed top-15 table sorts by the weighted composite score. Its identities, scores and order depend on the acquired snapshot and history; inspect them rather than assuming a fixed ranking. This mixed-date mechanics demonstration is not a historical investment signal. Robustness checks can vary clipping thresholds, missing-data treatment and factor weights.

In a production factor model, these raw factors would be sector-neutralized (ranked within industry rather than across the whole universe, to avoid a value tilt becoming an implicit bet against expensive sectors), standardized as z-scores rather than percentiles, and the weights would come from a factor-premium model or Black-Litterman rather than being set by hand, as the Multi-Factor Portfolio Construction activity at the end of Chapter 9 spells out.

def compute_momentum_factor(returns, lookback=12, skip=1):
    """Compute momentum factor: cumulative return over lookback months,"""
    if lookback < 1 or skip < 0:
        raise ValueError('lookback must be positive and skip nonnegative.')
    if len(returns) < lookback + skip:
        return pd.Series(dtype=float)

    # Use returns from t-lookback-skip to t-skip
    momentum_returns = returns.iloc[-(lookback+skip):len(returns)-skip]

    # Cumulative return over the period
    cumulative = (1 + momentum_returns).prod(min_count=lookback) - 1

    return cumulative

def compute_volatility_factor(returns, lookback=12):
    """Compute volatility factor: annualized standard deviation."""
    if len(returns) < lookback:
        return pd.Series(dtype=float)

    recent_returns = returns.iloc[-lookback:]
    volatility = recent_returns.std() * np.sqrt(12)  # Annualize

    return -volatility  # Negative so higher score = lower vol

def rank_normalize(series):
    """Convert values to percentile ranks (0 to 1)."""
    return series.rank(pct=True, na_option='keep')

def compute_composite_score(fundamentals, monthly_returns, weights=None):
    """Compute composite factor score for stock ranking."""
    if weights is None:
        weights = {
            'value': 0.25,
            'quality': 0.25,
            'momentum': 0.30,
            'low_vol': 0.20
        }

    factor_names = ['value', 'quality', 'momentum', 'low_vol']
    if set(weights) != set(factor_names) or any(v < 0 for v in weights.values()) or not np.isclose(sum(weights.values()), 1):
        raise ValueError('Factor weights must be nonnegative and sum to one.')
    scores = pd.DataFrame(index=fundamentals.index)

    # Value factor: inverse of P/E and P/B (lower is better)
    # Nonpositive valuation ratios are not cheapness signals. Clipping reduces
    # outlier impact but ties all observations above each cap (information lost).
    pe_capped = fundamentals['pe_ratio'].where(fundamentals['pe_ratio'] > 0).clip(upper=100)
    pb_capped = fundamentals['pb_ratio'].where(fundamentals['pb_ratio'] > 0).clip(upper=50)

    scores['value_pe'] = rank_normalize(-pe_capped)
    scores['value_pb'] = rank_normalize(-pb_capped)
    scores['value'] = (scores['value_pe'] + scores['value_pb']) / 2

    # Quality factor: high ROE, low leverage, high margins
    scores['quality_roe'] = rank_normalize(fundamentals['roe'])
    scores['quality_debt'] = rank_normalize(-fundamentals['debt_to_equity'].where(
        fundamentals['debt_to_equity'] >= 0).clip(upper=500))
    scores['quality_margin'] = rank_normalize(fundamentals['profit_margin'])
    scores['quality'] = (scores['quality_roe'] + scores['quality_debt'] +
                         scores['quality_margin']) / 3

    # Momentum factor
    momentum = compute_momentum_factor(monthly_returns.drop(columns=[BENCHMARK],
                                       errors='ignore'))
    scores['momentum'] = rank_normalize(momentum)

    # Low volatility factor
    low_vol = compute_volatility_factor(monthly_returns.drop(columns=[BENCHMARK],
                                        errors='ignore'))
    scores['low_vol'] = rank_normalize(low_vol)

    # Composite score (weighted average of factor ranks)
    scores['composite'] = (
        weights['value'] * scores['value'].fillna(0.5) +
        weights['quality'] * scores['quality'].fillna(0.5) +
        weights['momentum'] * scores['momentum'].fillna(0.5) +
        weights['low_vol'] * scores['low_vol'].fillna(0.5)
    )

    # Final rank
    scores['rank'] = scores['composite'].rank(ascending=False)

    return scores.sort_values('composite', ascending=False)

# Compute factor scores
# This snapshot mixes live fundamentals with the fixed historical price window.
# It demonstrates ranking mechanics, not a historical trade recommendation.
ranking_universe = fundamentals.index.intersection(monthly_returns.columns)
ranking_universe = ranking_universe[monthly_returns[ranking_universe].tail(13).notna().all()]
factor_scores = compute_composite_score(fundamentals.loc[ranking_universe], monthly_returns[ranking_universe])
print("Factor-Based Stock Ranking (Top 15):")
print(factor_scores[['value', 'quality', 'momentum', 'low_vol',
                     'composite', 'rank']].head(15).round(3))

Stock Selection: Top Quintile

This short block converts the ranking into a held portfolio by taking the top names, mirroring the long-leg construction of a factor portfolio described in the Factor Construction discussion. select_stocks sorts by composite and keeps the top percentile (here 20%), with a floor of max(10, ...) so the portfolio never shrinks below ten holdings; with 50 stocks the result is the top ten. The printed comparison of average factor scores for the selected ten against the full universe is the key diagnostic.

Read the selected-versus-universe averages as a tilt check. With \(n\) nonmissing observations, percentile ranks average \((n+1)/(2n)\) rather than exactly 0.5; clipping and missing-data imputation can also affect the reported averages. Compare each selected-factor average with the actual universe average to see whether the composite produces the intended exposures. These diagnostics can be repeated at each rebalance.

def select_stocks(factor_scores, n_stocks=None, percentile=0.20):
    """Select top-ranked stocks based on factor scores."""
    if not 0 < percentile <= 1 or (n_stocks is not None and n_stocks < 1):
        raise ValueError('Select a positive stock count or percentile in (0, 1].')
    sorted_scores = factor_scores.dropna(subset=['composite']).sort_values('composite', ascending=False)
    if sorted_scores.empty:
        raise ValueError('No eligible stocks to select.')

    if n_stocks is None:
        n_stocks = max(10, int(len(sorted_scores) * percentile))

    selected = sorted_scores.head(n_stocks).index.tolist()
    return selected

# Select top quintile
selected_stocks = select_stocks(factor_scores, percentile=0.20)
print(f"\nSelected Portfolio ({len(selected_stocks)} stocks):")
print(selected_stocks)

# Get factor exposures for selected stocks
selected_scores = factor_scores.loc[selected_stocks]
print(f"\nAverage factor scores for selected portfolio:")
print(selected_scores[['value', 'quality', 'momentum', 'low_vol']].mean().round(3))

print(f"\nAverage factor scores for full universe:")
print(factor_scores[['value', 'quality', 'momentum', 'low_vol']].mean().round(3))

The selected portfolio's factor averages describe this snapshot only; they do not establish that the same stocks or exposures were available historically.
